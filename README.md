# CinePrompt · 漫剧创作工作台

放入剧本，自动理解故事、统一人物与场景、拆分镜头，再生成每镜的视频提示词。默认入口为「自动创作」，面向即梦 / 小云雀 Seedance 2.5；保留逐步精修和单镜头工具。当前是带 Firebase 账号认证的网页软件，额度用于试用记账，在线充值暂未接入。

## 使用自动创作

1. 登录并验证邮箱，进入「自动创作」。粘贴剧本，或导入 / 拖入 TXT、MD、DOCX（最大5 MB，最多30,000字符）。
2. 选择即梦或小云雀、画幅、视觉方向与节奏，也可沿用默认设置。
3. 点击「自动生成分镜与提示词」。软件依次理解源文本、整理全局设定、规划分镜、生成提示词，显示实际阶段进度。
4. 对照每镜原文和对白，修改动作、摄影机或连续性，点击「保存修改」后再生成该镜头。长项目可搜索场景、人物、动作和对白，筛选待更新 / 未保存镜头，或按镜号快速定位；每页12镜，翻页保留本地修改。
5. 复制单镜提示词，或导出整个项目 JSON / 分镜文档。到即梦或小云雀上传自己的参考资产，并按真实素材编号绑定后生成视频。

新项目默认采用「电影叙事研究方法」，可在创作设置切换为「基于原文」。研究方法取自 SiJiafilm 的 [The Filter 公开工程](https://higgsfield.ai/@zsjcak/projects/the-filter)，重点是参考素材职责、可见表演变化、空间连续性、运镜动机、光色与声音的触发关系；只在剧本需要时采用主观感知或现实反转。设置中可查看六条原则、适用条件、一手来源和三个原创示例。

研究方法会参与阅读、全局理解、分镜规划及提示词生成。每镜的「创作意图」保存起始表演状态、变化触发、结束表演状态、空间锚点、运镜目的、光色与声音触发；不适用项可留空。修改后保存，会清除本镜及必要相邻镜的旧提示词，再用最新意图重新生成。意图随账号草稿、JSON备份和Markdown文档保存；切换方法需重新制作，不能沿用旧方法的中断进度。旧 version:1 备份未指定方法时沿用「基于原文」。

这些是公开材料中可核实的方法观察与原创转写，不是官方配方或成功率保证。作者的剧情、人物、平台素材编号和特定色调不会直接套进用户剧本。JSON研究材料作为内置方法的证据，项目恢复只接收创作项目格式。

这是剧本到分镜与提示词的创作软件，不调用 Seedance 视频生成，也不伪装为已上传素材。人物和场景输出目前是可复用的文字设定及参考职责计划，不是自动完成的参考图。

长剧本分块处理并保留来源范围；只有全部步骤通过后才替换旧完成项目。成功步骤保存为当前账号本机断点，中断或失败后可按相同剧本与设置继续；来源或设置变化会重新处理，避免混用。停止会取消后续步骤并向服务器传播取消，但已在供应商执行的请求仍可能计费。生成过程包含多次文本模型请求，不是一次调用完成所有镜头。

逐镜意图很长时，软件会缩小提示词批次，保留完整原文和意图；单镜仍超过请求预算时明确提示调整设定，保留已完成进度。明确标注的人物、旁白、对白和台词也会检查未带引号的新增内容；参考职责及表演说明与台词分开处理，无法确定的自由文本仍需人工复核。

对白来源与源文本、分镜覆盖、结构和可识别时间轴经过检查。支持带表演括号的角色台词、带引号的跨行台词及缩进续行；独立舞台标注按表演指令处理。说话人存在歧义时保留未归属状态，需人工复核。无法校验的叙事判断与语音/视频效果仍需人工复核；没有视频结果时，不能把文字检查当作成片质量分。

## 制作素材、光色与状态承接

完成自动创作后，展开「制作资料 · 素材职责与场景光色」，可从已有参考计划预填素材，记录身份与造型、场景与空间、道具、动作、音色、光色与材质、构图、白模与预演八类职责。每份素材明确采用、排除、主体身份组及适用镜头；同一人物多个视角归入同一身份。

文件选择只记录文件名，链接是可选的 HTTPS 元数据，不读取、托管或上传文件。实际在即梦或小云雀上传后，填写媒体类型和真实序号并勾选确认；复制正文才会加入对应平台的引用标记。更换文件记录会取消原确认。只有编号、链接或文件标签变化时，已有正文可继续使用，无需再次调用 AI；修改职责、主体或适用镜头会标记受影响的提示词待更新。

每个场景可保存一张光色卡，按需填写主光方向、软硬、环境主色、主体保护色、点缀色、明暗边界及允许变化。新提示词继承对应地点的卡片，不强制配色比例。修改光色卡只影响该地点的镜头。

每镜的「起止状态与相邻承接」记录位置、朝向、左右手持物、物件状态、运动方向、光源和未完成动作。自动分镜可提取有原文依据的状态或标为设计建议；只有用户能标记人工确认。相邻镜同场景的文字差异仅提醒核对，未知或跨场景不直接判为穿帮。修改状态会标记本镜及相邻镜提示词待更新。

新增资料随账号草稿和 JSON 项目备份保存，Markdown 导出含制作记录与实际复制正文。旧项目可直接恢复；未保存的编辑会阻止生成、导出和退出，起止状态编辑期间先保存或取消再翻页筛选。新一轮完整制作会建立新草案；需要保留现有制作资料时，优先逐镜重做提示词。

角色或场景原文引用不匹配时，修复请求会指出资产、错误摘录及原文中的短连续示例，最多自动修复一次。两次仍不匹配会保留已完成进度，不能把概括句伪装成原文证据。刷新页面后可使用「从中断处继续」；自带 API 密钥只在内存中，刷新后需重新填写。

本轮吸收了用户提供的《Seedance 2.5 提示词与全模态资产工作流指南》中素材职责、状态交接和场景光色的组织方法。未将固定字数、真人七段公式、60/30/10 色彩比例或 MOV 无损保证写成硬规则。模型/API 与国内入口能力以对应平台当前界面和[官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)为准。功能测试验证了文字、存储与操作流程，尚未进行实际视频质量对照试验。

## 界面 API 设置

登录并验证邮箱后，点击工作区顶部的「API设置」。文本接口与 Gemini 附图接口分别选择「服务端默认」或「自带密钥」。文本默认基础地址为 `https://api.deepseek.com/v1`，模型为 `deepseek-flash`；也可填写已经获部署者允许的聊天文本兼容地址与对应模型。Gemini 使用 Google 官方服务，可单独填写自己的密钥与模型。

「保存本次会话」只保存到当前账号的内存，不写入项目、JSON备份、localStorage或sessionStorage。刷新、离开、退出或切换账号后清除；生成期间不能应用或清除设置。配置保存没有真实连接测试，也不会自动调用收费接口。生成时服务器将本次密钥转发到所选且已允许的供应商，自带密钥请求不扣平台试用额度，供应商仍按用户账户规则计费。

服务端只允许官方基础地址和 `AI_ALLOWED_BASE_URLS` 中列出的完整 HTTPS 地址，拒绝不匹配的自定义目标及重定向。供应商正文回显本次密钥时拒绝提交成果；用量仅保留允许的数值字段。密钥不会作为提示词、参考素材或草稿数据传入导演流程。

## Vercel 部署

从 Vercel 导入 GitHub 仓库 `andromedaa1985-collab/mjtsc`，生产分支选 `main`。仓库包含 Vite 构建与 `api/index.ts` 服务端函数配置：Node.js 24、`npm run build`、静态输出 `dist`，API 路由保留 `/api/deepseek` 和 `/api/gemini`，普通页面使用 SPA 回退。Express API 工厂位于 `server/app.ts`，云上不监听端口或启动 Vite。

`vercel.json` 启用 Fluid Compute，API 函数最大时长为300秒。本地端口由 `server.ts` 管理。Vercel 单次请求体受平台限制，附图最大3 MiB；客户端和服务端同时限制最终 JSON 为4,300,000字节，包括 base64、Unicode 提示词和用户配置。图片与较长提示词组合仍可能超限，此时保留当前输入并提示减小图片。

若全部用户自带密钥，无需在 Vercel 配置供应商密钥。需要提供服务端默认接口时，在 Vercel 环境变量填写 `DEEPSEEK_API_KEY`／`GEMINI_API_KEY`，以及可选模型、超时与允许的兼容地址。真实密钥不能写入仓库、前端构建变量或 `VITE_*` 变量。新部署域名需加入对应 Firebase 项目的授权域名；保留原 `authDomain`，不要无依据更改认证项目或覆盖已有域名。Firestore规则仍需部署到原配置中的数据库。

部署完成后应验证首页和静态资源、匿名两个API均返回401、未知API返回JSON 404，以及真实账号的登录／邮箱验证与供应商生成。预览可打开不等于生产账号与真实模型已验收。内存限流只保护一个函数实例，不提供跨实例全局配额或正式收费保障。

## 本地运行

要求 Node.js 24 LTS（Vercel 与本地运行使用相同主版本）。

```sh
npm ci
```

复制 `.env.example` 为 `.env`。可填写 `DEEPSEEK_API_KEY` 提供服务端默认文本接口；`GEMINI_API_KEY` 用于附图分析。也可保留占位值，登录后在界面 API 设置中填写自己的本次会话密钥。然后运行：

```sh
npm run dev
```

访问 `http://localhost:3000`。服务器会加载 `.env`，密钥仅在服务器使用，不会注入浏览器构建。仓库历史曾包含供应商密钥，原持有人需要先在对应后台作废并换新；删除源码中的值不能撤销旧密钥。

Windows 也可在解压目录运行 `powershell -ExecutionPolicy Bypass -File .\Start-CinePrompt.ps1`。首次会建立 `.env` 后退出，填写自己的服务密钥再重新运行。启动脚本不包含任何预置密钥。

文本模型由服务器的 `DEEPSEEK_MODEL` 配置，默认 `deepseek-flash`，输出上限 `DEEPSEEK_MAX_OUTPUT_TOKENS` 默认16,000（允许1,024–32,768）。截至2026-10-13的[官方API文档](https://api-docs.deepseek.com/api/create-chat-completion/)已列出新的模型名称；服务器对默认模型关闭thinking模式，仍须用有效密钥做真实生成验收。输出被截断会返回明确错误，不把有效JSON前缀当作完成结果。

## 账号与部署

- `firebase-applet-config.json` 为前端公开配置。请确认对应 Firebase 项目的 Email/Password、Google 登录、授权域名和 Firestore 数据库设置；更换项目时需一并更新该文件。
- 两个 AI 接口必须携带 Firebase ID token，账号邮箱必须验证。服务器用配置中的 project ID 与 Firebase 公开签名证书验签，不需要用于数据库写入的服务账号；运行主机必须能够访问 Firebase 证书及供应商服务。
- 将 `firestore.rules` 部署到配置中的对应数据库。新账号只能初始化 100,000 试用积分；客户端只允许减少积分及编辑显示资料，不能提升权限或增加额度。规则文件的改变不会自动更新云端规则。
- 试用额度在成功请求后由客户端事务记账，不能用于真实收费或可信的余额准入。正式计费需服务端额度预留、扣费事务、支付回调和持久化限流。
- 内存限流为每个 UID 每分钟 20 次、同时 2 个请求，仅保护单个服务器实例。多实例部署需使用共享限流存储。

生产运行：

```sh
npm run build
npm start
```

`npm start` 使用生产静态构建，需要先执行 build。可设置 `PORT`（默认 3000）和 `AI_REQUEST_TIMEOUT_MS`（默认 90 秒，限制 1–300 秒）。生产主机必须提供相同的 `.env` 或环境变量。`npm run preview` 仅供前端构建预览，不提供 AI 接口。

## 创作行为

- 自动创作支持 TXT / MD / DOCX，中文文本编码会先做读取校验；GB18030回退会提示核对中文、标点与对白。旧 `.doc` 请先转换为 `.docx`，PDF / 扫描件暂不支持。逐步解析入口仍支持 DOCX / UTF-8 TXT。
- DOCX提取前检查普通ZIP的目录、条目尺寸和区域一致性，限制1,024条目、单XML/RELS 4 MiB、总声明展开内容16 MiB；过大、损坏或不支持的文件需另存为仅含剧本文字的TXT或普通DOCX。该预检依据声明元数据，不是完整恶意压缩文件防护。
- AI 输出经过结构校验后才替换已有内容。失败会保留剧本和旧结果，显示原因。长剧本的分镜分段全部完成后才提交；当前标签页内重试会复用已成功的分段。
- 自动创作可编辑动作、运镜、承接和时长。实质修改会清除本镜及必要相邻镜的旧提示词，也移除旧续作进度，避免续作覆盖人工修订；仅首尾空格的无变化保存保留进度。旧项目可恢复其原文与设置并撤销。逐步精修入口还支持场景与人物编辑。
- 同一工作区中的编辑基础发生变化时，本地分镜文字仍保留，需明确核对并决定是否保留改过的字段；原文摘录变化时不能直接套用旧编辑。未保存修改期间，退出账号、项目导入及导出会暂时禁用。
- 旧version:1项目的对白仅在精确匹配上一版提取结果时按原文迁移；受影响镜头提示词标为待更新，其他已完成阶段保留。补全对白超过当前时长时保留原词并提示拆镜，生成前阻止超载，不删台词。
- 视频生成参考当前分镜、相邻片段和匹配的人物/场景；“色彩关系”和“镜头目的与空间路径”支持主动控制。生成正文与后期完成建议分开，复制按钮只复制生成正文。
- 时间轴检查仅提示可识别时间段的空隙、重叠或总时长不一致，不能保证生成的视频满足要求。
- 主流程草稿按账号保存于当前浏览器，包含剧本、人物、分镜、镜头参数与视频提示词；可导出JSON备份。可选成果或断点损坏时分别恢复可读取的剧本与有效成果，并暂停保存保留原始值；坏设置可从原文一致的合法进度恢复，备份后再启用保存。旧版无账号草稿须主动导入。
- 保存前核对浏览器版本，并监听另一标签页的更新。检测到较新草稿时暂停本窗口自动保存，选择保留本窗口或载入浏览器版本前先导出另一份备份。此检查覆盖常规顺序的陈旧写入；localStorage读取和写入不构成跨进程原子事务，尚不提供完全同时写入的事务保证或多人协作。
- 已访问步骤保持挂载，切换步骤保留正在编辑的文字和请求状态；单镜头工具的未提交文字目前仅在当前工作区会话内保留。账号退出后组件会卸载。

## 参考研究

[docs/creative-reference-research.json](docs/creative-reference-research.json) 记录用户指定原片、国外作者材料、实际抽样覆盖及通用创作规则。研究包含三部抖音原片与 Paul Trillo 官方 Vimeo 的 59 张抽帧观察，以及 shy kids 的一手制作访谈。

作品观察、公开作者 prompt 与本次新写候选 prompt 分别记录。抽帧分析不能证明全片剪辑频率、音频表现、真实镜头设备或 LUT；新规则也尚未做真实 AI 生成效果验收。视频创作规则集中于 `src/lib/creativePrompts.ts`。

[docs/seedance25-production-research.json](docs/seedance25-production-research.json) 保存2026-10-13核验的国内入口、参考限制、原作者实践和8条原创模板。2.5常规单段为4–30秒；小云雀的5分钟工作流利用延长能力，4K属于提升画质，不能移作原生请求参数。正式接入视频API时应重新核验当前入口。

[docs/sijiafilm-creative-methods.json](docs/sijiafilm-creative-methods.json) 保存 The Filter 方法的来源、条件和研究边界；应用的阶段导引和原创示例集中在 `src/lib/directorMethods.ts`。没有把抽样记录数量视为成片采用镜头数，也未将提示词中的帧率、分辨率或质量措辞视为实测成绩。
